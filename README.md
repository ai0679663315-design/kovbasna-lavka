# Ковбасна лавка

Інтернет-магазин продукції «Жадківські ковбаси» (продаж за згодою виробника).
Статичний сайт: `index.html` + `products.js` (асортимент і ціни з Telegram-каналу @Zhadkivski).

- **Замовлення** надсилаються у Make (вебхук → сховище «Замовлення ковбас»).
- **Фото** беруться з каналу; GitHub Actions (`sync-product-photos`) зберігає локальні копії в `img/`.
- **Націнка**: `MARKUP` на початку скрипта в `index.html` (зараз 0 — ціни виробника).
- **Ціни/асортимент**: правити `products.js`.

## Публікація
1. GitHub Pages: Settings → Pages → Source: *Deploy from a branch* → `main` / root.
2. Власний домен: купити домен (напр. на imena.ua / nic.ua), у DNS додати записи
   GitHub Pages (A-записи 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
   або CNAME на `<акаунт>.github.io`), потім Settings → Pages → Custom domain → увімкнути HTTPS.
